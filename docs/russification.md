# План русификации ГУ Deepal S07 2026

Документ описывает только исследование и подготовку. Запись в ГУ, прошивки
и работа с блоками автомобиля сюда не входят.

## Принципы

1. Оригиналы не изменяются. Любая правка делается на копии.
2. Сначала читаем и проверяем, потом собираем, потом ставим.
3. Один изменяемый пакет за раз. Не «весь `/system` сразу».
4. Перед установкой — копия оригинального APK и известный способ отката.
5. Не трогаем ECU, MCU, `ro.hardware.ecu.config.*`, сертификаты и загрузчик.
6. Не обходим защиту производителя: если пакет подписан и не ставится —
   это ответ, а не препятствие, которое надо ломать.

## Три технических пути

| Путь | Суть | Риск | Откат |
|---|---|---|---|
| **RRO-оверлей** | отдельный APK с ресурсами, оригинал не меняется | низкий | отключить/удалить оверлей |
| Правка `resources.arsc` | пересобрать APK с русскими строками | средний | вернуть оригинальный APK |
| Замена APK целиком | собрать новый APK с кодом | высокий | только при наличии копии и доступа |

Приоритет: RRO → правка ARSC → замена. RRO предпочтителен, потому что
оригинальный файл остаётся нетронутым, а откат не требует переустановки.

Ограничение: RRO работает, только если целевое приложение читает ресурсы
через `Resources` и не кэширует строки. Это проверяется на живом APK.

## Что нужно, чтобы начать

1. APK хотя бы одного пакета с ГУ. Кандидаты по полезности:
   `com.mega.carsettings`, `com.mega.media`, `com.mega.sceneblock`,
   `com.mega.btphone`, `com.mega.car`.
2. Понимание, как ставится и удаляется APK на этом ГУ.
3. Копия оригинального APK, снятая до любых экспериментов.

Без пункта 1 дальше идти нельзя: формат `resources.arsc` чувствителен к
выравниванию и пулам строк, на синтетике его не проверить.

## Конвейер

```
инвентаризация → извлечение строк → перевод → проверка → сборка → установка → проверка → откат
```

| Шаг | Инструмент | Условие перехода |
|---|---|---|
| Инвентаризация | `--analyze`, `--resources` | видно, какие пакеты и строки есть |
| Извлечение | `--resources --translation-csv` | шаблон без технических строк |
| Перевод | внешний редактор CSV | колонка `translation` заполнена |
| Проверка | `--check-translations` | код возврата 0 |
| Сборка | writer ARSC / RRO | APK собирается и разбирается обратно |
| Установка | штатный установщик ГУ | приложение запускается |
| Проверка | экран ГУ | русский текст, нет «квадратов» |
| Откат | копия APK / отключение оверлея | ГУ возвращается в исходное состояние |

## Порядок перевода пакетов

1. **Настройки** `com.mega.carsettings` — максимальная польза, низкий риск.
2. **Медиа** `com.mega.media`, `com.kugou.android.auto` — частые экраны.
3. **Сценарии** `com.mega.sceneblock`, `com.mega.scenemode`.
4. **Телефон** `com.mega.btphone`.
5. **Лаунчер и HMI** `com.deepal.ivi.hmi.showcarmode`, `com.mega.car`.
6. **Системные диалоги** `com.android.systemui`, `com.android.settings`.

Начинать с системных диалогов не стоит: ошибка там заметна сразу и
затрагивает весь интерфейс.

## Что не переводим

- технические атрибуты (`android:id`, `layout_*`, `permission`, `path*`);
- имена пакетов, классов, MIME-типы;
- строки с плейсхолдерами без сохранения `%1$s`, `{0}`, `<b>`;
- названия брендов и моделей;
- строки, где перевод ломает раскладку (кнопки фиксированной ширины).

Фильтр уже реализован в `core/axml.py` и `core/translation.py`.

## Безопасность и откат

- Перед экспериментами: копия APK, скриншот текущего состояния, запись
  версии сборки.
- Не ставить APK из непроверенных источников, особенно «русификаторы»
  с форумов.
- Не менять `ro.hardware.ecu.config.*`, не нажимать `下线配置功能`,
  `证书导入功能`, `恢复出厂设置`.
- Признаки проблемы: приложение не запускается, ГУ уходит в перезагрузку,
  пропадает звук или камера. Тогда сразу откат, без повторных попыток.
- Гарантия отката есть только при наличии оригинального APK и способа его
  установить. Пока способ установки неизвестен, установку не начинаем.

## Открытые вопросы

1. Как на этом ГУ устанавливается APK: `应用商城`, ADB, USB-режим?
2. Проверяется ли подпись при установке системных пакетов?
3. Читается ли `/system` без root (косвенно — да, логи это делают).
4. Поддерживает ли прошивка RRO-оверлеи.
5. Есть ли штатный способ удалить установленный пакет.
