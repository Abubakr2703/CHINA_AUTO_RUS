# CHINA AUTO RUS

Windows-приложение для исследования и последующей русификации мультимедийных систем
китайских автомобилей. Первый профиль — **Changan Deepal S07 2026, китайская версия,
рестайлинг**.

> Статус: **Этап 2.2 — рабочий интерфейс и анализатор готовы**. Следующий шаг — языковые ресурсы.

## Задачи MVP

1. Импорт файлов и папок с компьютера.
2. Анализ структуры, форматов и содержимого файлов.
3. Поиск и извлечение языковых ресурсов для перевода на русский.

Дополнительно: SHA-256, дерево файлов, отчёт анализа, сохранение оригиналов,
логирование ошибок.

## Стек

- Python 3.12+
- PySide6 (GUI)
- pytest, ruff, mypy (dev)
- SQLite — только если появится реальная необходимость

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"

python -m china_auto_rus
python -m china_auto_rus --check
python -m china_auto_rus --analyze "C:\path\to\dump"
python -m china_auto_rus --analyze "C:\path\to\dump" --no-hash
pytest
ruff check .
mypy
```

`--analyze` — временная точка проверки ядра без GUI: сканирует папку или файл,
считает SHA-256, определяет форматы, читает текст (UTF-8/UTF-16/GBK), перечисляет
содержимое ZIP/APK и сохраняет отчёт в `workspace/reports/`.

## Интерфейс

Запуск без аргументов открывает окно:

- «Открыть файл…» / «Открыть папку…» или drag & drop;
- вкладка **Файлы** — путь, размер, формат, SHA-256;
- вкладка **Дерево** — структура каталогов;
- вкладка **Ошибки** — файлы, которые не удалось прочитать;
- справа — предпросмотр: кодировка, текст, содержимое ZIP/APK;
- «Сохранить отчёт» — JSON + Markdown в `workspace/reports/`;
- «Отмена» останавливает анализ после текущего файла;
- чекбокс `SHA-256` можно снять для быстрого прохода по большим дампам.

Анализ выполняется в `QThread`, поэтому окно не зависает.

## Безопасность

- Исходные файлы открываются **только на чтение** и не изменяются.
- Никаких подключений к электронным блокам автомобиля.
- Прошивки не записываются, защита производителя не обходится.
- Образы прошивок и бинарные артефакты не коммитятся в git.
- Неизвестные форматы не модифицируются вслепую.
