# CHINA AUTO RUS

Windows-приложение для исследования и последующей русификации мультимедийных систем
китайских автомобилей. Первый профиль — **Changan Deepal S07 2026, китайская версия,
рестайлинг**.

> Статус: **Этап 1 — каркас проекта**. Интерфейс и анализатор ещё не реализованы.

## Задачи MVP

1. Импорт файлов и папок с компьютера.
2. Анализ структуры, форматов и содержимого файлов.
3. Поиск и извлечение языковых ресурсов для перевода на русский.

Дополнительно: SHA-256, дерево файлов, отчёт анализа, сохранение оригиналов,
логирование ошибок.

## Стек

- Python 3.12+
- PySide6 (GUI)
- pytest, ruff (dev)
- SQLite — только если появится реальная необходимость

## Структура

```
src/china_auto_rus/
├── __main__.py       # точка входа: python -m china_auto_rus
├── config.py         # пути, профиль автомобиля, версия
├── logging_setup.py  # файловые и консольные логи
├── core/             # бизнес-логика (без импортов PySide6)
└── ui/               # интерфейс (Этап 2)
tests/                # pytest
workspace/            # рабочие копии и отчёты (в .gitignore)
logs/                 # логи (в .gitignore)
```

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"

python -m china_auto_rus
python -m china_auto_rus --check
pytest
ruff check .
```

## Безопасность

- Исходные файлы открываются **только на чтение** и не изменяются.
- Никаких подключений к электронным блокам автомобиля.
- Прошивки не записываются, защита производителя не обходится.
- Образы прошивок и бинарные артефакты не коммитятся в git.
- Неизвестные форматы не модифицируются вслепую.
